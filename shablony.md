# Шаблони

## Шапка файлу курсової для build_docx.py

Перші рядки `kursova.md` між `---`. Порожнє поле = рядок з підкресленнями на титулці.

```
---
variant: A                       # A = ЕФП-2024 (пункти з нової сторінки, «Таблиця» праворуч); B = ФТМ-2023
kafedra: Кафедра маркетингу
dyscyplina: Маркетинг
tema: Оцінка ефективності цифрових рекламних каналів підприємства та напрями її підвищення
baza: ТОВ «Назва», м. Київ
kurs: 2
hrupa: 
fakultet: торгівлі та маркетингу
specialnist: D5 Маркетинг
prohrama: Маркетинг
student: Прізвище Ім'я По батькові
stat: студента                  # студента / студентки
kerivnyk: доцент кафедри маркетингу, канд. екон. наук, Прізвище І. Б.
misto: Київ
rik: 2026
sources_order: alpha            # alpha = за алфавітом; mention = за порядком першої згадки
cite_sep: ";"                   # роздільник у [1; 5], як вимагає кафедра (";" або ",")
---
```

## Розмітка тексту

```
# ВСТУП                                  ← структурна частина (з нової сторінки)
# 1. ТЕОРЕТИЧНІ ЗАСАДИ ...               ← пункт основної частини
## 1.1. Назва підпункту                  ← підпункт (тільки для складного плану)
Звичайний абзац тексту з посиланням [3; 7] і на таблицю (табл. 2.1).

Таблиця 2.1: Динаміка основних показників ТОВ «Назва» за 2023-2025 рр.
| Показник | 2023 | 2024 | 2025 |
|---|---|---|---|
| Чистий дохід, тис. грн | 10 120,0 | 10 640,5 | 12 598,2 |
Джерело: сформовано автором за даними [21].

![Рис. 2.1. Структура витрат на маркетинг ТОВ «Назва» у 2025 р.](img/ris_2_1.png)
Джерело: розроблено автором.

$$ ROMI = (Д − В) / В × 100 % $$ (3.1)
де Д - дохід від маркетингових заходів, грн;
В - витрати на маркетингові заходи, грн.

- елемент переліку;
- останній елемент.

[[PAGEBREAK]]
# СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ
1. Прізвище І. Б. Назва ...
2. ...

# ДОДАТКИ
## Додаток А
### Фінансова звітність ТОВ «Назва» за 2023-2025 рр.
...
```
- `# ЗМІСТ` писати не треба: скрипт сам ставить титулку і зміст.
- Для посилань на джерела в чернетці можна писати `[@ключ]`, де ключ = мітка джерела у `dzherela.md` (наприклад `[@kotler2007]`); `build_docx.py` у режимі `sources_order: mention` або `alpha` замінить ключі на номери. Простий шлях: одразу писати номери.

## Лист керівнику з планом на погодження

```
Тема: Курсова робота, [дисципліна]: план на погодження, [Прізвище І.], гр. [__]

Доброго дня, [Ім'я По батькові]!

Надсилаю на погодження тему і план курсової роботи з дисципліни «[дисципліна]».

Тема: «[тема]» (за матеріалами [підприємство]).

План:
Вступ
1. [...]
2. [...]
3. [...]
4. [...]
Висновки та пропозиції

Інформаційна база: [фінзвітність за 2023-2025 рр., дані рекламних кабінетів, опитування NN респондентів].

Буду вдячний(а) за зауваження.

З повагою,
[ПІБ], [група], [корпоративна пошта]
```

## Робоча папка курсової

```
Університет/Курсові/<Дисципліна> (<рік>)/
├── _стан.md            ← етап, дедлайни, що зроблено, наступний крок
├── tema-i-plan.md      ← тема, об'єкт, предмет, мета, завдання, план + «що доводить» кожен пункт
├── dzherela.md         ← картки джерел, статус перевірки
├── dani/               ← звітність, вигрузки, результати опитування (сирі)
├── img/                ← рисунки і графіки
├── kursova.md          ← текст з шапкою (джерело правди)
├── build/              ← Курсова_<Прізвище>.docx (генерується)
└── zakhyst/            ← доповідь, презентація, відповіді на рецензію
```
