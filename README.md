# kursova-dteu

Скіл (набір інструкцій і скриптів) для **Claude**, який допомагає написати курсову роботу в **Державному торговельно-економічному університеті** (ДТЕУ, колишній КНТЕУ) від вибору теми до захисту. Зроблено під маркетинг, але вимоги до оформлення і структури загальні для всіх кафедр ДТЕУ.

Після встановлення достатньо написати Claude звичайними словами, наприклад «допоможи з курсовою з маркетингу», і він сам підхопить вимоги ДТЕУ, правила ДСТУ і порядок роботи.

## Що вміє

- **Вимоги ДТЕУ** з офіційних документів: Положення про курсові роботи, методички кафедр 2023-2024. Сюди входять терміни, структура, обсяги, критерії оцінювання (55/15/30 і 90/10) і 12 типових помилок.
- **Оформлення** за ДСТУ 3008:2015 і методичками: поля, шрифт, заголовки, таблиці, рисунки, формули, додатки, титулка.
- **Список джерел** за ДСТУ 8302:2015: шаблони записів і місця, де шукати справжні джерела. Головне правило: жодного вигаданого джерела.
- **План маркетингової курсової**: тема, об'єкт, предмет, мета, завдання, 4 пункти, методи аналізу, формули, рекомендації з розрахунком ефекту.
- **Текст**: науковий стиль, шаблони вступу і висновків, як не звучати як ChatGPT.
- **Перевірка за шкалою ДТЕУ** перед здачею.
- **Захист**: доповідь, презентація, ймовірні питання комісії.
- **Готовий файл Word** (.docx), оформлений за вимогами: титулка, зміст, нумерація, таблиці, список джерел.
- **Автоперевірка** готової роботи: поля, шрифт, посилання [1] ↔ список, формат джерел, обсяг.

## Варіант 1. У браузері (claude.ai), найпростіше

1. **Зареєструйся** на [claude.ai](https://claude.ai) (можна через Google-акаунт).
2. **Завантаж скіл.** Відкрий сторінку [Releases](https://github.com/t1seP/kursova-dteu/releases/latest) і скачай файл **`kursova-dteu.zip`**. Розпаковувати його не треба.
   > ⚠ Не натискай зелену кнопку «Code → Download ZIP» на головній сторінці. Той архів має іншу назву папки, і Claude його не прийме.
3. **Увімкни виконання коду.** На claude.ai натисни на своє ім'я внизу ліворуч → **Settings** → **Capabilities** → увімкни **«Code execution and file creation»** (у новому інтерфейсі пункт може називатися **«Create and edit files»**).
4. **Додай скіл.** У меню ліворуч знайди **Customize** → **Skills** → кнопка **«+»** → **«+ Create skill»** → **«Upload a skill»** → вибери скачаний `kursova-dteu.zip`.
5. Переконайся, що перемикач біля **kursova-dteu** увімкнений.
6. Готово. Відкрий новий чат і напиши, наприклад: *«Допоможи з курсовою з маркетингу, я на 2 курсі ДТЕУ»*.

Офіційна інструкція Anthropic: [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude).

**Як отримати файл Word:** коли текст готовий, напиши *«збери курсову в docx»*. Claude дасть файл для завантаження. Відкрий його у Word, клацни правою кнопкою по тексту «Зміст з'явиться після оновлення...» на другій сторінці і вибери **«Оновити поле»**. Зміст із номерами сторінок з'явиться сам.

## Варіант 2. Claude Code на комп'ютері (повні можливості)

Тут Claude працює прямо з файлами у твоїй папці: сам створює і зберігає курсову, збирає Word, оновлює зміст і рахує сторінки. Потрібна платна підписка Claude (Pro або вища).

### Крок 1. Встанови Claude Code

**Найпростіше: застосунок.** Скачай **Claude** для Windows або macOS з [claude.com/download](https://claude.com/download), встанови, увійди і відкрий вкладку **Code**.

**Або через термінал (Windows):**
1. Натисни **Пуск**, набери `PowerShell` і відкрий його.
2. Встав цю команду (правою кнопкою миші) і натисни Enter:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
3. Закрий вікно, відкрий PowerShell знову і набери `claude`. Відкриється браузер для входу в акаунт.

На macOS відкрий програму **Terminal** і встав `curl -fsSL https://claude.ai/install.sh | bash`.
Офіційна інструкція: [code.claude.com/docs/en/setup](https://code.claude.com/docs/en/setup).

### Крок 2. Встанови Python (потрібен для збірки Word)

**Windows:** у PowerShell встав і натисни Enter:
```powershell
winget install Python.Python.3.12
```
Або скачай з [python.org/downloads](https://www.python.org/downloads/). Під час встановлення **обов'язково постав галочку «Add python.exe to PATH»**.

**macOS:** Python зазвичай уже є. Якщо ні, скачай з [python.org/downloads](https://www.python.org/downloads/).

### Крок 3. Встанови скіл

**Найпростіше: попроси Claude.** Запусти Claude Code і напиши:

> Встанови скіл з https://github.com/t1seP/kursova-dteu у мою папку скілів ~/.claude/skills/kursova-dteu і встанови python-docx

Claude сам скачає файли і поставить потрібний пакет. Він може питати дозволу на кожну дію, відповідай «Yes».

**Або вручну:**
1. Скачай [`kursova-dteu.zip`](https://github.com/t1seP/kursova-dteu/releases/latest) і розпакуй.
2. Скопіюй папку `kursova-dteu` сюди:
   - Windows: `C:\Users\<твоє ім'я>\.claude\skills\` (папка `.claude` прихована: встав шлях `%USERPROFILE%\.claude\skills` в адресний рядок Провідника; якщо папки `skills` немає, створи її);
   - macOS: `~/.claude/skills/`.
3. У терміналі виконай `pip install python-docx` (на macOS `pip3 install python-docx`).

### Крок 4. Перевір

Створи папку для навчання (наприклад, `Документи\Університет`) і відкрий її в Claude Code (у застосунку: вибери папку; у терміналі: `cd` у папку і `claude`). Напиши:

> Які в тебе є скіли для курсової?

Claude має назвати **kursova-dteu**. Якщо не називає, перезапусти Claude Code.

## Як користуватися

Просто пиши, що треба. Claude сам іде за етапами і не перестрибує їх.

| Етап | Що написати |
|---|---|
| Початок | «Допоможи з курсовою з маркетингу, 2 курс ДТЕУ, кафедра маркетингу» |
| Тема | «Не знаю, яку тему обрати, я працюю в кав'ярні / магазині / агенції» |
| План | «Склади план за темою "...", база ТОВ "..."» |
| Методичка | прикріпи файл методички або силабусу: «ось методичка кафедри, врахуй» |
| Джерела | «Знайди 30 джерел за ДСТУ 8302 за моєю темою» |
| Текст | «Напиши пункт 2, ось фінзвітність підприємства» (прикріпи дані) |
| Word | «Збери курсову в docx» |
| Перевірка | «Перевір мою курсову» (прикріпи .docx) |
| Захист | «Підготуй доповідь на 5 хвилин і питання комісії» |

**Чесно про межі:**
- Цифри підприємства, відповіді опитування і джерела мають бути **справжніми**. Скіл забороняє Claude їх вигадувати. Нема даних, то Claude скаже, що зібрати.
- Ти маєш розуміти свою роботу: до 30 балів із 100 ставлять на захисті за відповіді на питання. Проси Claude пояснювати кожен пункт.
- **Методичка твоєї кафедри і слова керівника важать більше за цей скіл.** Прикріпи методичку на початку.

## Часті питання і проблеми

**Claude не приймає zip («Upload failed»).** Ти скачав архів кнопкою «Code → Download ZIP». Потрібен файл `kursova-dteu.zip` зі сторінки [Releases](https://github.com/t1seP/kursova-dteu/releases/latest).

**Claude не бачить скіл.** Варіант 1: перевір, що перемикач скіла увімкнений і виконання коду теж. Варіант 2: перевір шлях `.claude\skills\kursova-dteu\SKILL.md` (саме так, без зайвої вкладеної папки) і перезапусти Claude Code.

**`claude` не знайдено / `'irm' is not recognized`.** Перша помилка: закрий і відкрий термінал знову. Друга: ти в CMD, а не в PowerShell, відкрий саме PowerShell.

**`python` або `pip` не знайдено.** Python встановлено без галочки «Add to PATH». Перевстанови з галочкою або на Windows використовуй `py` замість `python` і `py -m pip install python-docx`.

**У Word замість змісту якийсь текст.** Клацни по ньому правою кнопкою → «Оновити поле» → «Оновити повністю».

**Безкоштовного плану вистачить?** Для варіанту 1 так, але ліміт повідомлень на день невеликий, тож курсову доведеться писати за кілька днів. Claude Code (варіант 2) на безкоштовному плані недоступний.

**У мене Mac / немає Word.** Усе працює, крім автоматичного оновлення змісту і підрахунку сторінок. Зміст оновлюється в Word, Pages або LibreOffice вручну.

**Це не плагіат?** Скіл вчить писати своїми словами з посиланнями на джерела і забороняє вигадувати факти. ДТЕУ перевіряє роботи на плагіат, тому дослівні шматки тільки в лапках з посиланням. Відповідальність за роботу лежить на тобі.

## Для тих, хто вміє в термінал

```bash
git clone https://github.com/t1seP/kursova-dteu.git ~/.claude/skills/kursova-dteu
pip install python-docx

# демо
cd ~/.claude/skills/kursova-dteu/example
python ../scripts/build_docx.py kursova.md --update --pdf     # --update/--pdf лише Windows + Word
python ../scripts/check_kursova.py build/Курсова_Демо.docx --online --min-src 5
```
`example/kursova.md` це демо верстки, підприємство і цифри вигадані.

Структура:
```
SKILL.md                 точка входу: паспорт курсової, 7 режимів, залізні правила
vymohy-dteu.md           вимоги ДТЕУ з посиланнями на першоджерела
oformlennya.md           оформлення (ДСТУ 3008:2015 + методички)
dzherela-dstu-8302.md    пошук джерел і список за ДСТУ 8302:2015
struktura-i-metody.md    тема, план, типи маркетингових тем, методи, формули
pysannya.md              як писати: абзац, теорія, аналіз, вступ, висновки, стиль
perevirka.md             гейти, самооцінка, чеклисти
zakhyst.md               доповідь, презентація, питання комісії
shablony.md              шапка файлу, розмітка, заява, бланк-завдання, лист керівнику
scripts/                 build_docx.py, check_kursova.py, word_com.py (Word через PowerShell COM, без pywin32)
example/                 демо
```

Оновлення: `cd ~/.claude/skills/kursova-dteu && git pull`, або скачай новий zip з Releases і заміни папку.
