# kursova-dteu

Скіл для Claude Code: курсова робота в Державному торговельно-економічному університеті (ДТЕУ, колишній КНТЕУ) від вибору теми до захисту. Зроблено під маркетинг, але вимоги до оформлення і структури загальні для всіх кафедр ДТЕУ.

## Що вміє

- **Вимоги ДТЕУ** з офіційних документів: Положення про курсові роботи, методички кафедр 2023-2024 (терміни, структура, обсяги, критерії оцінювання 55/15/30 і 90/10, 12 типових помилок). Розбіжності між кафедрами зведено в таблицю.
- **Оформлення** за ДСТУ 3008:2015 і методичками: поля, шрифт, заголовки, таблиці, рисунки, формули, додатки, титулка.
- **Список джерел** за ДСТУ 8302:2015: шаблони для кожного типу джерела, де шукати відкриті джерела, правило «жодного вигаданого джерела».
- **Маркетингова курсова**: як сформулювати тему, об'єкт, предмет, мету і завдання; план із 4 пунктів; 7 типів тем з методами, формулами і джерелами даних; рекомендації з розрахунком ефекту.
- **Текст**: науковий стиль українською, огляд літератури за ідеями, шаблон вступу і висновків, анти-AI правила.
- **Гейти якості** на кожному етапі та самооцінка за шкалою ДТЕУ.
- **Захист**: структура доповіді, презентація, питання комісії.
- **Скрипти**:
  - `scripts/build_docx.py`: markdown з шапкою перетворює на .docx за вимогами (титулка, зміст, нумерація, таблиці, рисунки, формули, список, додатки). Якщо є Microsoft Word, оновлює зміст, рахує сторінки і зберігає PDF.
  - `scripts/check_kursova.py`: перевіряє .docx або .md. Дивиться поля, шрифт, інтервал, структуру, тире, першу особу, кліше, відповідність посилань і списку, формат ДСТУ 8302, свіжість джерел, згадки таблиць і рисунків, обсяг. З `--online` перевіряє, що URL і DOI відповідають.

## Встановлення

```bash
git clone https://github.com/t1seP/kursova-dteu.git ~/.claude/skills/kursova-dteu
pip install python-docx
```
Перезапусти Claude Code. Скіл підхоплюється за словами «курсова», «план курсової», «список джерел ДСТУ», «оформи курсову», «захист курсової».

Оновлення змісту і підрахунок сторінок працюють тільки на Windows з Microsoft Word (через PowerShell COM, pywin32 не потрібен). Без Word docx теж збирається, а зміст оновлюється в Word вручну: правою кнопкою, «Оновити поле».

## Швидкий старт

```bash
cd example
py ../scripts/build_docx.py kursova.md --update --pdf
py ../scripts/check_kursova.py build/Курсова_Демо.docx --word --online --min-src 5
```
`example/kursova.md` це демо верстки. Підприємство і цифри в ньому вигадані, як зразок змісту його не використовувати.

## Важливо

- Методичка твоєї кафедри і вказівки керівника завжди важать більше за цей скіл.
- Документи ДТЕУ тут не розповсюджуються. Вимоги переказано своїми словами з посиланнями на оригінали на knute.edu.ua (станом на 27.10.2026).
- Скіл допомагає зробити роботу, але не підміняє її. Джерела, цифри і відповіді респондентів мають бути справжніми, а автор повинен розуміти кожен абзац, бо до 30 балів вирішуються на захисті.
